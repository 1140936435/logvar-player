# LogVar Player (mplay) — 需求分析报告（更新版）

> **日期**：2026-06-17
> **分析范围**：基于最新代码的全面审计，涵盖功能实现、代码质量、安全性和改进方向

---

## 🏗️ 项目现状总结

| 维度 | 状态 |
|------|------|
| **技术栈** | Electron 33 + React 19 + TypeScript + TailwindCSS v4 + Framer Motion |
| **视频播放** | **双后端**：mpv 主播放器（Win32 嵌入） + HTML5 `<video>` 降级 |
| **弹幕系统** | Canvas 渲染引擎，支持 DandanPlay + B站 + 本地 XML，含密度/速度控制 |
| **媒体源** | Jellyfin 多服务器 + 本地文件 |
| **UI 风格** | iOS 26 毛玻璃风格，双主题（light/dark），macOS 风格窗口控制 |
| **代码规模** | 核心代码 ~4500+ 行，主进程 2600+ 行，Player 组件 1900+ 行 |

## ✅ 已实现功能清单

### 1. Jellyfin 媒体库集成（完整）
- **多服务器管理**：添加、编辑、删除、切换（支持多 Jellyfin 实例）
- **媒体库浏览**：层级下钻（Library → Movie/Series → Season → Episode）
- **全库搜索**（Movie/Series/Episode）
- **播放进度上报**（`Sessions/Playing/Progress` + `Sessions/Playing/Stopped`）
- **收藏切换**（`toggleFavorite`）
- **剧集列表**：电视剧自动加载季/集列表，支持集数切换
- **海报刮削**：从豆瓣搜索海报并本地缓存持久化
- **启动时自动重连上次活跃服务器**
- **旧单服务器格式 → 新多服务器格式自动迁移**

### 2. 弹幕系统（核心功能，完整）
- **自动匹配弹幕**：多策略匹配（原始标题 → 清洗标题 → DandanPlay API → B站 API 回退）
- **DandanPlay API**：主 API + 多镜像备用 + 自动重试 + 连接测试
- **Bilibili 弹幕**：搜索番剧 → 获取 cid → 下载 XML 弹幕 → 解析
- **本地 XML 弹幕**：自动查找同名 `.xml` / `.cmt.xml` / `.danmaku.xml`
- **Canvas 弹幕引擎**：
  - 滚动弹幕（mode 1）、顶部固定弹幕（mode 5）、底部固定弹幕（mode 4）
  - 可调参数：透明度、字号（12-48px）、速度（60-300 px/s）、密度（50-500）
  - 时间密度控制（每秒最多显示条数）
  - 跳播检测：前进/后退时自动清理/定位弹幕
  - 轨道占用避免重叠
- **弹幕缓存**：本地 JSON 缓存（`userData/danmaku_cache/`）
- **弹幕预下载**：匹配成功后预下载整季弹幕
- **弹幕设置面板**：播放器内弹出设置
- **弹幕搜索面板**：手动搜索并选择弹幕来源

### 3. 本地文件播放（完整）
- **打开文件/文件夹**：系统对话框选择视频文件
- **文件夹扫描**：支持 mp4/mkv/avi/mov/wmv/flv/webm/m4v/ts/m2ts/rmvb
- **`local-file://` 自定义协议**处理本地文件流（支持 Range 请求）
- **视频信息**：ffprobe 获取技术参数（编码、分辨率、帧率、码率等）

### 4. 播放器 UI（完整）
- **自定义控制栏**：播放/暂停、进度条（带缓冲指示）、时间显示
- **音量控制**：滑块弹窗 + 静音切换
- **倍速播放**：0.5x/0.75x/1x/1.25x/1.5x/2x
- **全屏**：F 键/按钮切换
- **剧集切换**：上一集/下一集 + 集数列表弹窗
- **播放历史**：自动保存进度（每 5 秒 + 退出时），支持恢复播放位置
- **沉浸式控制栏**：鼠标不动 3 秒自动隐藏
- **右键菜单**：影片信息、视频源信息、播放速度、弹幕开关/搜索/加载
- **影片信息覆盖层**：片名、年份、类型、时长、评分、简介
- **视频源信息覆盖层**：分辨率、编码、帧率、码率、色深、HDR、音频、字幕等
- **画中画 (PiP)**：原生 HTML5 PiP + mpv 窗口置顶降级
- **截图功能**：mpv + Canvas 降级，支持文件保存对话框
- **窗口控制**：最小化、最大化、关闭（所有页面均显示）
- **AB 循环**：区间循环播放

### 5. 首页（Home）
- **媒体卡片**：海报 + 评分角标 + 刮削按钮
- **播放历史卡片**：进度条 + 时间显示 + 播放/删除
- **面包屑导航**：层级下钻
- **服务器切换**：下拉菜单
- **豆瓣刮削**：搜索海报 → 下载本地 → 持久化映射
- **多状态视图**：loading / not_connected / error / empty / ready

### 6. 详情页（Detail）
- **媒体详细信息展示**（年份、评分、类型、简介、演职人员）
- **电视剧季/集列表**
- **直接播放按钮**

### 7. 设置页（Settings）
- **Jellyfin 服务器管理**：添加/编辑/删除/连接/测试
- **弹幕 API 配置**：主 API + 备用镜像 + 测试连接
- **播放器设置**：硬件解码、HDR 色调映射（UI 开关，但**未实际持久化**）

### 8. 系统功能
- **自定义标题栏**：无边框窗口 + iOS 风格关闭/最小化/最大化按钮
- **系统托盘**：双击显示、右键菜单（显示窗口/日志/退出）
- **日志系统**：独立日志窗口（Ctrl+Shift+L）、日志文件持久化、日志脱敏、5000 条内存缓冲
- **深色/浅色主题**：跟随系统或手动切换
- **快捷键**：F12 开发者工具、Ctrl+Shift+L 日志窗口
- **配置加密**：safeStorage 加密（已启用，敏感数据加密存储）

## ✅ 优先级 P0：关键功能（已实现）

### 1. 媒体库分页 UI ✅

`Home.tsx` 已实现分页加载：`LIBRARY_PAGE_SIZE = 50`，每页加载 50 项，底部有"加载更多"按钮，显示剩余项数。

### 2. 播放器设置持久化 ✅

`Settings.tsx` 中的 `hardwareDecode` 和 `hdrToneMapping` 开关已通过 `store.set('player', ...)` 持久化保存，主进程从 `configData['player']` 读取并传递给 mpv 控制器。

### 3. 字幕/音频轨道选择 UI ✅

播放器控制栏已实现轨道选择按钮（仅在有多轨道时显示），弹出菜单支持音频轨道切换、字幕轨道切换、关闭字幕。支持 mpv 和 HTML5 双模式。

## 🟡 优先级 P1：体验优化

### 4. 快捷键可视化反馈不统一

当前快捷键操作（快进/快退/音量/倍速）有 `showStatus` 提示，但：
- 倍速切换的 toast 提示不统一
- 缺少快捷键列表展示
- 缺少“按 `?` 显示快捷键帮助”

**建议**：统一 toast 提示样式，添加快捷键帮助弹窗。

### 5. 播放历史页面独立化

当前播放历史只在首页顶部展示一行卡片，没有独立的历史管理页面。

**建议**：添加 `/history` 路由，支持搜索、筛选、批量删除。

### 6. 弹幕密度控制的 `timeDensity` 未暴露

`DanmakuEngine` 有 `timeDensity`（每秒最多显示条数）控制，但 UI 中已被移除（注释掉了）。密度控制只通过 `maxCount`（活跃轨道数）实现。

**建议**：恢复时间密度控制滑块，与轨道密度分开调节。

### 7. 视频技术信息展示不完整

`video:get-info` 返回丰富的技术参数（编码、分辨率、帧率、码率、色深、HDR 等），但 UI 中只展示了部分信息。

**建议**：在影片信息覆盖层中展示完整的技术参数。

## 🟢 优先级 P2：功能增强（对标市面主流播放器）

### 8. 播放列表 / 队列管理

> 对标：PotPlayer、VLC

- 本地文件夹扫描后生成播放列表
- 支持拖拽排序
- 自动连播下一集
- 随机播放 / 循环模式

### 9. 视频截图预览（缩略图） ✅ 已实现

> 对标：YouTube、B站进度条缩略图

鼠标悬停进度条时显示该时间点的缩略图预览。通过隐藏的离屏 `<video>` 元素 seek 到悬停时间点，使用 Canvas 绘制缩略图帧。支持缓存（每 2 秒一帧缓存），节流 80ms 防止频繁 seek。

### 10. 弹幕发送功能

> 对标：B站

支持向 LogVar API 发送弹幕（需要 API 支持 POST 接口）。

### 11. 多语言 / i18n

> 对标：VLC、mpv

当前 UI 全中文，如果将来有国际化需求，建议早期引入 i18n 框架（如 `react-i18next`）。

### 12. 网络串流播放 ✅ 已实现

> 对标：VLC

支持 `http://`、`https://`、`rtsp://`、`rtmp://`、`mms://`、`udp://` 等网络串流地址直接播放。首页已有网络串流输入框，Player 自动检测 URL 类型：mpv 模式直接播放所有协议；HTML5 模式支持 http/https 流。

### 13. 均衡器 / 音效调节

> 对标：PotPlayer、foobar2000

mpv 支持 `audio-filter` 和 `equalizer`，可以实现简单的均衡器 UI。

### 14. 自动连播 (Autoplay)

> 对标：Netflix、B站

播放完当前集后，自动倒计时并播放下一集（带 5 秒倒计时 UI）。

### 15. 手势控制（触屏/触控板）

> 对标：IINA

- 双指捏合缩放
- 左右滑动快进/快退
- 上下滑动调节音量/亮度

### 16. 全局快捷键

> 对标：PotPlayer

注册系统级全局快捷键（如 `Ctrl+Alt+Space` 暂停/播放），即使窗口不在前台也能控制。
