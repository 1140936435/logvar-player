## ✅ 已实现功能清单

### 1. Jellyfin 媒体库集成
- 多服务器管理：添加、编辑、删除、切换
- 媒体库浏览：层级下钻（Library → Movie/Series → Season → Episode）
- 全库搜索（Movie/Series/Episode）
- 播放进度上报（`Sessions/Playing/Progress`）
- 收藏切换（`toggleFavorite`）
- 剧集列表：电视剧自动加载季/集列表，支持集数切换
- 海报刮削：从豆瓣搜索海报并本地缓存持久化
- 启动时自动重连上次活跃服务器
- 旧单服务器格式 → 新多服务器格式自动迁移

### 2. 弹幕系统（核心功能）
- 自动匹配弹幕：多策略匹配（原始标题 → 清洗标题 → DandanPlay API → B站 API 回退）
- DandanPlay API：主 API + 多镜像备用 + 自动重试 + 连接测试
- Bilibili 弹幕：搜索番剧 → 获取 cid → 下载 XML 弹幕 → 解析
- 本地 XML 弹幕：自动查找同名 `.xml` / `.cmt.xml` / `.danmaku.xml`
- Canvas 弹幕引擎：
  - 滚动弹幕（mode 1）、顶部固定弹幕（mode 5）、底部固定弹幕（mode 4）
  - 可调参数：透明度、字号（12-48px）、速度（60-300 px/s）、密度（50-500）
  - 时间密度控制（每秒最多显示条数）
  - 跳播检测：前进/后退时自动清理/定位弹幕
  - 轨道占用避免重叠
- 弹幕缓存：本地 JSON 缓存（`userData/danmaku_cache/`）
- 弹幕预下载：匹配成功后预下载整季弹幕
- 弹幕设置面板：播放器内弹出设置
- 弹幕搜索面板：手动搜索并选择弹幕来源

### 3. 本地文件播放
- 打开文件/文件夹：系统对话框选择视频文件
- 文件夹扫描：支持 mp4/mkv/avi/mov/wmv/flv/webm/m4v/ts/m2ts/rmvb
- `local-file://` 自定义协议处理本地文件流（支持 Range 请求）
- 视频信息：ffprobe 获取技术参数（编码、分辨率、帧率、码率等）

### 4. 播放器 UI
- 自定义控制栏：播放/暂停、进度条（带缓冲指示）、时间显示
- 音量控制：滑块弹窗 + 静音切换
- 倍速播放：0.5x/0.75x/1x/1.25x/1.5x/2x
- 全屏：F 键/按钮切换
- 剧集切换：上一集/下一集 + 集数列表弹窗
- 播放历史：自动保存进度（每 5 秒 + 退出时），支持恢复播放位置
- 沉浸式控制栏：鼠标不动 3 秒自动隐藏
- 右键菜单：影片信息、视频源信息、播放速度、弹幕开关/搜索/加载
- 影片信息覆盖层：片名、年份、类型、时长、评分、简介
- 视频源信息覆盖层：分辨率、编码、帧率、码率、色深、HDR、音频、字幕等

### 5. 首页（Home）
- 媒体卡片：海报 + 评分角标 + 刮削按钮
- 播放历史卡片：进度条 + 时间显示 + 播放/删除
- 面包屑导航：层级下钻
- 服务器切换：下拉菜单
- 豆瓣刮削：搜索海报 → 下载本地 → 持久化映射
- 多状态视图：loading / not_connected / error / empty / ready

### 6. 详情页（Detail）
- 媒体详细信息展示（年份、评分、类型、简介、演职人员）
- 电视剧季/集列表
- 直接播放按钮

### 7. 设置页（Settings）

## 🔴 优先级 P0：关键缺失功能

### 1. mpv 播放器未实际集成

preload 中声明了完整的 `mpv.*` API，但主进程**没有实现任何 IPC handler**。当前使用 HTML5 `<video>` 元素，导致：

- ❌ MKV/AVI/RMVB 等格式无法播放
- ❌ 无硬件解码（DXVA2/D3D11VA）
- ❌ 无 HDR 色调映射
- ❌ 无内嵌字幕渲染（ASS/SSA 样式丢失）

**建议**：优先实现 mpv 控制器，这是项目的核心定位。`koffi` 和 `node-mpv` 已作为依赖安装，只需实现主进程的 `MpvController`。

### 2. 字幕轨道选择缺失

当前播放器没有任何字幕/音频轨道切换 UI。对于多音轨、多字幕的视频文件（常见于蓝光压制），用户无法选择。

**建议**：mpv 集成后，通过 mpv IPC 获取 `track-list`，在控制栏添加字幕/音频切换按钮。

### 3. 音频轨道切换缺失

与字幕同理，多音轨视频（如国日双音轨）无法切换。

### 4. 播放进度上报不完整

当前只上报 `Progress` 事件，缺少 `Stopped` 事件（播放结束时上报完成状态），Jellyfin 服务端可能无法正确标记"已看完"。

**建议**：在 `onEnded` 时调用 `Sessions/Playing/Stopped`。

## 🟡 优先级 P1：体验优化

### 5. 媒体库分页加载不完整

`Home.tsx` 的 `jellyfin:get-items` 默认 `limit: 50`，没有滚动加载更多。大型媒体库（100+ 部）无法完整浏览。

**建议**：实现 Intersection Observer 无限滚动 + "加载更多"。

### 6. 快捷键可视化反馈

当前快捷键操作（快进/快退/音量/倍速）有 `showStatus` 提示，但：

- 倍速切换的 toast 提示不统一
- 缺少快捷键列表展示
- 缺少"按 `?` 显示快捷键帮助"

### 7. 播放历史页面独立化

当前播放历史只在首页顶部展示一行卡片，没有独立的历史管理页面。

**建议**：添加 `/history` 路由，支持搜索、筛选、批量删除。

### 8. 设置页面的播放器设置无实际效果

`Settings.tsx` 中的 `hardwareDecode` 和 `hdrToneMapping` 开关只是前端 state，没有持久化也没有传递给 mpv。

**建议**：mpv 集成后，将这些设置映射为 mpv 的 `hwdec` 和 `tone-mapping` 参数。

### 9. 配置加密功能被禁用

`encryptValue` / `decryptValue` 函数体被注释掉，Jellyfin Token 等敏感数据以明文存储在 `config.json`。

**建议**：修复 safeStorage 加密，或至少提供可选的加密开关。

### 10. 弹幕密度控制的 `timeDensity` 未暴露

`DanmakuEngine` 有 `timeDensity`（每秒最多显示条数）控制，但 UI 中已被移除（注释掉了）。密度控制只通过 `maxCount`（活跃轨道数）实现。

**建议**：恢复时间密度控制滑块，与轨道密度分开调节。

## 🟢 优先级 P2：功能增强（对标市面主流播放器）

### 11. 画中画 (PiP) / 小窗置顶

> 对标：PotPlayer、IINA、mpv 原生支持

小窗口置顶播放，方便边看边做其他事。Electron 原生支持 `BrowserWindow.setAlwaysOnTop`。

### 12. 截图功能

> 对标：PotPlayer、VLC、mpv

播放中按 `S` 截取当前帧保存为图片。mpv 有 `screenshot` 命令原生支持。

### 13. AB 循环 (区间循环)

> 对标：PotPlayer、VLC

设置 A/B 点，反复播放指定区间。对语言学习、舞蹈练习等场景非常有用。

### 14. 播放列表 / 队列管理

> 对标：PotPlayer、VLC

- 本地文件夹扫描后生成播放列表
- 支持拖拽排序
- 自动连播下一集
- 随机播放 / 循环模式

### 15. 视频截图预览（缩略图）

> 对标：YouTube、B站进度条缩略图

鼠标悬停进度条时显示该时间点的缩略图预览。可以预生成关键帧缩略图。

### 16. 弹幕发送功能

> 对标：B站

支持向 LogVar API 发送弹幕（需要 API 支持 POST 接口）。

### 17. 多语言 / i18n

> 对标：VLC、mpv

当前 UI 全中文，如果将来有国际化需求，建议早期引入 i18n 框架（如 `react-i18next`）。

### 18. 网络串流播放

> 对标：VLC

支持 `rtmp://`、`rtsp://`、`m3u8` 等网络串流地址直接播放。

### 19. 均衡器 / 音效调节

> 对标：PotPlayer、foobar2000

mpv 支持 `audio-filter` 和 `equalizer`，可以实现简单的均衡器 UI。

### 20. 自动连播 (Autoplay)

> 对标：Netflix、B站

播放完当前集后，自动倒计时并播放下一集（带 5 秒倒计时 UI）。

### 21. 手势控制（触屏/触控板）

> 对标：IINA

- 双指捏合缩放
- 左右滑动快进/快退
- 上下滑动调节音量/亮度

### 22. 全局快捷键

> 对标：PotPlayer

注册系统级全局快捷键（如 `Ctrl+Alt+Space` 暂停/播放），即使窗口不在前台也能控制。

## 🔧 代码质量优化

| 问题 | 位置 | 建议 |
|------|------|------|
| **zustand 未使用** | `package.json` | 全部用 `useState` 管理状态，组件间共享状态通过 props drilling。建议引入 zustand 管理全局播放状态 |
| **Player.tsx 过于庞大** | ~1400 行 | 拆分为 `PlayerControls`、`DanmakuOverlay`、`EpisodeList`、`VideoInfo` 等子组件 |
| **`webSecurity: false`** | `main/index.ts` | 安全风险，建议只对 `local-file://` 协议放宽限制 |
| **日志窗口 `nodeIntegration: true`** | `main/index.ts` | 安全风险，建议改为 contextBridge 模式 |
| **缺少 Error Boundary** | React 组件 | 添加全局错误边界防止白屏 |
| **Bilibili 非官方 API** | `main/index.ts` | `search/type?search_type=media_bangumi` 接口不稳定，建议添加降级策略 |
| **无单元测试** | 全项目 | 建议至少为核心模块（弹幕引擎、API 匹配）添加测试 |
| **`electron-store` 依赖未使用** | `package.json` | 移除无用依赖，减小打包体积 |
| **`koffi`/`node-mpv` 依赖未使用** | `package.json` | 实现 mpv 控制器后才有意义 |
