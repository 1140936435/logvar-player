# 弹幕分区显示与防重叠轨道算法 - 产品需求文档

## Overview
- **Summary**: 实现弹幕显示区域自定义配置和多行弹幕轨道防重叠算法，参考 DPlayer/danmaku.js 成熟方案，确保弹幕在指定区域内有序滚动且完全不重叠。
- **Purpose**: 解决弹幕遮挡视频主体内容问题，提升观看体验；解决大量弹幕同时出现时的重叠挤压问题。
- **Target Users**: 所有使用播放器观看带弹幕视频的用户

## Goals
- 支持配置弹幕画布上下边界（百分比/像素），限制弹幕仅在指定区间滚动
- 设置面板新增边界调节滑块，配置持久化保存
- 实现多行弹幕轨道分配逻辑，保证同时间弹幕完全不重叠
- 轨道仅生成在限定的弹幕区域内，不占用视频画面其余部分
- 动态复用闲置轨道，优化性能
- 倍速、拖拽跳转后重新分配轨道依然保持无重叠

## Non-Goals (Out of Scope)
- 弹幕样式自定义（颜色、字体等已有实现）
- 弹幕关键词过滤（不在本次需求范围内）
- 弹幕透明度动画（已有实现）
- 硬件加速渲染优化

## Background & Context
当前弹幕引擎使用碰撞检测机制，但缺少：
1. 可配置的弹幕显示区域边界
2. 成熟的轨道分配算法
3. 轨道复用机制

参考方案：DPlayer 的轨道分配算法采用"碰撞范围列表"模式，维护每条轨道的占用状态，新弹幕分配时查找空闲轨道，超出区域的弹幕自动丢弃。

## Functional Requirements
- **FR-1**: 支持配置弹幕显示区域的上边界（topBoundary）和下边界（bottomBoundary），支持百分比和像素两种单位
- **FR-2**: 设置面板新增两个滑块控制上下边界，参数存入 localStorage 持久化
- **FR-3**: 播放、拖拽进度、倍速切换时，分区规则实时生效
- **FR-4**: 超出设定边界的弹幕自动销毁，不会溢出画面
- **FR-5**: 实现多行弹幕轨道分配逻辑，保证同时间出现的横向滚动弹幕完全不重叠
- **FR-6**: 轨道仅生成在限定的弹幕区域内
- **FR-7**: 动态复用闲置轨道，优化大量弹幕同时加载的性能
- **FR-8**: 倍速、拖拽跳转后重新分配轨道，保持无重叠效果

## Non-Functional Requirements
- **NFR-1**: 弹幕渲染性能不低于现有实现（保持 60fps）
- **NFR-2**: 内存占用不显著增加（活跃弹幕数保持 maxActiveComments 限制）
- **NFR-3**: 倍速切换时轨道重新分配无明显卡顿
- **NFR-4**: 拖拽跳转后弹幕重新定位时间 < 100ms

## Constraints
- **Technical**: Electron + React + TypeScript + Canvas 2D
- **Dependencies**: 不引入新的第三方库，基于现有架构实现
- **Backward Compatibility**: 不破坏现有弹幕播放、API 匹配、进度同步功能

## Assumptions
- 弹幕轨道高度基于字体大小计算（fontSize * 1.5）
- 默认边界：topBoundary=0%，bottomBoundary=100%（全屏）
- 横向滚动弹幕（rtl/ltr）使用轨道分配，顶部/底部固定弹幕使用中心定位

## Acceptance Criteria

### AC-1: 弹幕区域边界配置
- **Given**: 用户打开弹幕设置面板
- **When**: 用户拖动上边界滑块到 20%，下边界滑块到 80%
- **Then**: 弹幕仅在视频画面 20%-80% 区域内显示
- **Verification**: `human-judgment`

### AC-2: 边界配置持久化
- **Given**: 用户设置了弹幕边界并重启软件
- **When**: 重新打开播放器并播放视频
- **Then**: 弹幕显示区域保持上次设置的边界
- **Verification**: `programmatic`

### AC-3: 轨道防重叠
- **Given**: 同时有 10 条横向滚动弹幕到达屏幕
- **When**: 弹幕开始滚动
- **Then**: 所有弹幕分布在不同轨道上，无任何重叠
- **Verification**: `human-judgment`

### AC-4: 轨道复用
- **Given**: 弹幕轨道被占用后弹幕离开屏幕
- **When**: 新的弹幕到达
- **Then**: 新弹幕自动分配到闲置轨道
- **Verification**: `programmatic`

### AC-5: 倍速切换后无重叠
- **Given**: 播放过程中有多条弹幕在屏幕上
- **When**: 用户切换倍速（如 1x → 2x）
- **Then**: 弹幕重新分配轨道，依然无重叠
- **Verification**: `human-judgment`

### AC-6: 拖拽跳转后无重叠
- **Given**: 用户拖拽进度条跳转到新位置
- **When**: 新位置有大量弹幕
- **Then**: 弹幕正常显示，无重叠挤压
- **Verification**: `human-judgment`

### AC-7: 超出边界弹幕自动销毁
- **Given**: 弹幕分配的轨道位置超出边界
- **When**: 弹幕准备显示
- **Then**: 弹幕被自动丢弃，不进入渲染队列
- **Verification**: `programmatic`
